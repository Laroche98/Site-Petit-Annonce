# Documents pour Cursor – Plateforme de Petites Annonces (Côte d'Ivoire)

Ces documents sont conçus pour être utilisés avec **Cursor** et ses agents IA.

## Liste des documents

| # | Fichier | Description |
|---|---------|-------------|
| 01 | `01_PRD.md` | Product Requirements Document – Vision, objectifs, fonctionnalités |
| 02 | `02_TRD.md` | Technical Requirements Document – Stack technique et contraintes |
| 03 | `03_APPFLOW.md` | Application Flow – Parcours utilisateurs et pages |
| 04 | `04_UI_UX_DESIGN.md` | Direction design – Couleurs, typo, principes UX (très important) |
| 05 | `05_BACKEND_SCHEMA.md` | Schéma de base de données Supabase |
| 06 | `06_IMPLEMENTATION_PLAN.md` | Plan d’implémentation étape par étape |

## Comment utiliser avec Cursor

1. Ouvre le projet dans Cursor
2. Mets tous ces fichiers dans un dossier `/docs` ou à la racine
3. Dans le chat de Cursor (Agent / Composer), commence par :

```
Voici le PRD, TRD, App Flow, UI/UX Design, Backend Schema et Implementation Plan de mon projet de plateforme de petites annonces en Côte d'Ivoire.
Commence par la Phase 0 et Phase 1 de l'Implementation Plan.
Respecte strictement le design system défini dans le document UI/UX.
Pas de paiement en ligne dans cette version.
```

4. Avance phase par phase.

## Points importants rappelés

- Pas de paiement en ligne dans le MVP
- Design très soigné et premium (priorité)
- Mobile-first
- Gratuit pour les particuliers
- Payant pour les pros (immobilier + auto) via validation manuelle au début
- Chat intégré pour discuter avec les vendeurs / magasins

Bon développement !
